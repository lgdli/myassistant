Una colección de proyectos comunitarios construidos en MyAssistant.

:::note
¿Quieres agregar tu proyecto relacionado con MyAssistant a esta lista? Envíe un PR.
:::

También puedes consultar [awesome-myassistant](https://github.com/awesome-myassistant/awesome-myassistant) y [myassistant.cafe](https://myassistant.cafe), una comunidad que agrega el ecosistema y la comunidad.
