Eine Sammlung von Community-Projekten, die auf MyAssistant basieren.

:::note
Möchten Sie Ihr MyAssistant-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-myassistant](https://github.com/awesome-myassistant/awesome-myassistant) und [myassistant.cafe](https://myassistant.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
